# Crystal Palace FC Analytics Dashboard

An interactive Streamlit dashboard that analyzes Crystal Palace FC match performance using Python, Pandas, and Plotly.

## Features

- Season Performance Dashboard
- Match Statistics Analysis
- Advanced Metrics Visualization
- Opponent Scouting Reports
- Radar Charts
- Interactive Filtering

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
